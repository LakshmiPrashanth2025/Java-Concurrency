# Java Concurrency Examples

This project contains Java concurrency examples including:

1. Thread Example
2. Runnable Example
3. Synchronization Example
4. ExecutorService Example
5. Atomic Variables Example
6. CompletableFuture Example
7. Virtual Threads Example

## Build

mvn clean compile

## Run Example

mvn exec:java -Dexec.mainClass="com.example.concurrency.ThreadExample"
